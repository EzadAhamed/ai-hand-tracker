# AI Hand Tracker

A simple computer vision project for real-time hand detection and tracking using Python and OpenCV.

## Features
- Real-time hand tracking from a webcam
- Landmark-based hand detection
- Reusable tracking module
- Beginner-friendly computer vision project

## Main Files
- `HandTrackingModule.py` — reusable hand tracking logic
- `prop.py` — demonstration script for using the tracker

## Requirements
- Python 3.9+
- OpenCV
- NumPy

## Installation
```bash
git clone https://github.com/EzadAhamed/ai-hand-tracker.git
cd ai-hand-tracker
pip install opencv-python numpy
```

## Usage
```bash
python prop.py
```

You can also import `HandTrackingModule` into your own Python scripts for custom hand-tracking workflows.

## Notes
This repository is intended for learning and experimenting with computer vision and hand detection.
